# 每周学习节奏

一次有效循环由四部分组成：

1. 阅读：只读当前章节需要的概念，写下三个待验证的问题。
2. 实现：先完成最小可见版本，再做额外优化。
3. 观察：使用 ImGui、中间 Texture、日志、截图，或在平台支持时使用 GPU 截帧工具验证每个 Pass 的输入输出。
4. 复盘：记录错误现象、根因、修复和仍不理解之处。

建议每周安排两次 90 分钟实现、一次 60 分钟阅读、一次 30 分钟复盘。每次提交只做一件事，例如“加入深度测试”，不要把模型加载、光照和 UI 混在同一个提交中。

## 目录约定

每个代码练习使用 exercises/NN_name/：

~~~text
exercises/02_cpu_rasterizer/
  README.md
  src/
  assets/
  screenshots/
  notes.md
~~~

screenshots/ 保存验收图；notes.md 记录本阶段独有的坑。外部依赖版本写入 README，不依赖机器上的“恰好能用”环境。
