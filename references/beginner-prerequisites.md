# 零基础前置知识

本书从图形学零基础开始，但不会从“如何输入 C++ 代码”开始。开始第 1 章前，确认以下内容。

## 1. 最少的数学

你需要会四则运算、分数和坐标平面。三角函数、向量和矩阵会在书中讲解；不需要预先背公式。看到 (x, y, z) 时，把它先理解成“三个数字描述的位置或方向”。

## 2. 最少的 C++

以下代码要能看懂大意：

~~~cpp
float speed = 3.0f;              // 保存一个小数
int count = 10;                  // 保存一个整数

float add(float a, float b) {    // 定义一个函数
    return a + b;                // 给出结果
}

for (int i = 0; i < count; ++i) { // 重复 count 次
    // 使用 i 做某件事
}
~~~

float 表示小数，int 表示整数，bool 表示 true 或 false。函数的圆括号内是输入，return 后面的值是输出。for 用于重复工作，渲染器常用它遍历顶点、像素或物体。

## 3. 先建立的直觉

- CPU：运行游戏规则、组织数据、向 GPU 发命令的处理器。
- GPU：大量并行执行相同小程序、特别擅长处理顶点和像素的处理器。
- 内存：数据存放的位置；CPU 内存与 GPU 内存是不同区域。
- 帧：显示器上的一张完整画面。60 FPS 表示每秒尝试产生 60 张画面。

## 4. 不必先学的内容

不需要预先学习 Vulkan、PBR、四元数、线性代数教材、物理引擎、ECS 或多线程。它们会在真正需要时出现。

## 5. 遇到卡点时

先回答“我不知道的是词、公式、代码语法，还是数据为什么这样流动”。只解决一个问题后再继续。把问题写入 plan/progress.md，而不是靠记忆积压。

## 6. 数组、结构体和引用

渲染器会大量使用数组。数组是一串同类型数据，例如所有 Vertex、所有 Pixel 或所有 RenderItem。索引从 0 开始：

~~~cpp
std::vector<int> values = {10, 20, 30};
int first = values[0]; // 10
~~~

struct 把相关字段放在一起：

~~~cpp
struct Color {
    float r;
    float g;
    float b;
};
~~~

引用符号 & 常表示“不复制对象，直接使用原对象”。修改引用会修改原数据。图形缓冲通常很大，因此函数会通过引用传递。

## 7. 头文件与源文件

.h 或 .hpp 通常放类型和函数声明，.cpp 放实现。每个 .cpp 会先独立编译为目标文件，再由链接器组合成程序。看到 undefined symbol 时，常意味着声明存在，但实现没有参与链接。

## 8. 浮点数不是精确小数

float 在计算机中只能近似表示许多小数。0.1 + 0.2 不一定精确等于 0.3。图形学会频繁使用容差：

~~~cpp
if (std::abs(a - b) < 0.0001f) {
    // 把它们视为相等
}
~~~

深度、阴影 bias、矩阵求逆等问题都会受到浮点精度影响。
